A two-part micro-confession: a `To:` line naming who it was meant for, and
the unsent message itself, one line exactly as it was typed.

> To: my sister
>
> I was the one who broke your camera the summer before college. I let you blame the movers for three years because saying sorry felt smaller than the lie.

Run `node main.ts` (with `MAKEFUN_OUTPUT_DIR` set to choose where
`entry.txt` is written). The program writes the confession to
`entry.txt`, checks the gate (1–260 characters total, message at most 200
characters, not only whitespace), and prints the sha256 of what it wrote.
